### DM40 instrument operation and resources

The expanded DM40 reference covers the oscilloscope, multimeter and waveform-generator functions, controls and measurements, a low-energy first check, storage/export behavior, diagnostics and the official software/document resources. Instrument and probe ratings, common references and actual input conditions must be considered together.

The guide does not assume galvanic isolation or a remote automation API. The unavailable official archive and unverified firmware/recovery contract are identified, so an example filename or USB connection is not mistaken for a tested flashing or automation procedure.
