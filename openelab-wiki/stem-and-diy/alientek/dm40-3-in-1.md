## Getting started

1. Confirm model suffix, firmware, installed fuse and included probe/lead types. Read the current manual for input limits and charging/USB grounding restrictions.
2. For the first test, use an isolated, known low-voltage DC source. Connect leads to COM and the specified voltage terminal with voltage measurement selected.
3. Measure the reference and compare with a trusted instrument. Disconnect before changing terminal or function.
4. Only after checking the manual, use a documented low-voltage test waveform with the appropriate probe setting and common reference. Do not infer isolation from battery operation.
5. Record mode, range, probe attenuation, firmware and reference value so that discrepancies can be reproduced.

**Expected checkpoint:** A stable reading on a known low-voltage reference with the correct terminals and no overload indication.

## Development software and recovery

No public automation SDK or remote-control protocol was confirmed. The manufacturer's resource package is the starting point for firmware, manuals and supported data functions; do not install unrelated DM40-family firmware solely because the name looks similar. If a reading is implausible, check mode, jack, lead continuity and fuse state before suspecting calibration.
