# M5Stack Glass Transparent OLED

### M5Stack Glass Unit w/ 1.51 inch Transparent OLED

***

{% embed url="https://openelab.io/products/glass-unit-w-transparent-oled" %}

### Description <a href="#description" id="description"></a>

`Unit Glass` is a `1.51-inch transparent OLED` expansion screen unit. It adopts `STM32+SSD1309` driver scheme,`resolution is 128*64`, monochrome display, `transparent area is 128*56`. The MCU adopts `STM32F030F4P6`, which integrates `two input buttons` and `one way buzzer` to facilitate user interaction with the screen, and supports control and firmware upgrade through I2C (addr: `0x3D`) communication interface. This transparent OLED screen extension is suitable for embedding in various `home products` or `various control devices as a display panel`.

### Features <a href="#features" id="features"></a>

* 128x56 transparent pixels (128x64 total pixels)
* Display area 35.5 x 18mm
* Glass area 42mm x 27.16mm
* 1-bit color depth
* I2C operation
* I2C Addresses: 0x3D
* Support for programming platforms：Arduino、UIFlow

### Applications <a href="#applications" id="applications"></a>

* Home products
* DIY toys
