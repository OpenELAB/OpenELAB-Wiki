### Description <a href="#description" id="description"></a>

**BLACK-BOTTOM\_V1.1** is a universal base launched for the Basic (Core) console. Compared to the previous generation Core Bottom, the base is equipped with a battery switch at the bottom to extend battery life. It houses a 110mAh lithium battery internally and features 2.54mm spaced pin headers and female headers for convenient user expansion. The base also incorporates embedded magnets for magnetic attachment, making it suitable for a variety of scenarios.

The bottom sticker pin corresponds to the M5Core host, and check the corresponding host pin when matching Core2 and CoreS3.

### Features <a href="#features" id="features"></a>

* Compatible with M5Core/Core2/CoreS3
* Magnetic base
* 110mAh battery
* Battery operated switch
