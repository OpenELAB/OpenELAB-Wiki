Vision Master T190 (HT-VMT190) is a development kit with ESP32-S3 and LoRa Module (optional). The onboard 1.9-inch TFT-LCD display contains 170 (RGB)X320 dots and can display up to 262k colors.

Working with the sample programs and development tools we provide, users can operate the display via Bluetooth, Wi-Fi and LoRa. It also supports daily entry-level programming, and runs open source projects like Meshtastic.

<figure><img src="../../.gitbook/assets/image (271).png" alt=""><figcaption></figcaption></figure>

Feature

* ESP32-S3R8 MCU, support Wi-Fi and BLE.
* LoRa module is optional, compatible with Mashtastic.
* Low power consumption, 18uA in deep sleep.
* Onboard SH1.25-2 battery interface, integrated lithium battery management system (charge and discharge management, overcharge protection, battery power detection, USB / battery power automatic switching).
* Powerful display function, onboard 1.9-inch TFT-LCD display contains 170 (RGB)X320 dots and can display up to 262k colors.
* Storage condition: -30 \~ 70℃, ≤45%RH.
* Optimal operating condition：-20\~60℃, 55±10%RH.
* SH2.0-4P sensor interface is compatible with QuickLink series sensors.
* Compatible with Arduino, we provide development frameworks and libraries.

### FAQ

{% step %}
#### Can the onboard 2.4GHz antenna be replaced?



The default configuration of T190 board is PCB antenna, and the 2.4GHz antenna is a spring antenna. There is an additional interface on the board for 2.4GHz wireless signals. When connecting an external antenna, the resistor needs to be rotated 90 degrees to the left.

<img src="https://heltec.org/wp-content/uploads/2024/06/resistance-300x300.png" alt="" height="300" width="300">

What development methods does it support?

* Arduino
* Micro Python
* PlatformIO
* Espressif IDE

We strongly recommend using Arduino. We have complete technical support and provide complete [LoRaWAN code for ESP32 Arduino framework](https://github.com/Heltec-Aaron-Lee/WiFi_Kit_series/tree/master/esp32/libraries/LoraWan102).
{% endstep %}

{% step %}
What’s the battery socket type?

You can find this type of socket by search “SH1.25 x 2”.
{% endstep %}

{% step %}
I can not find serial port.

1. Please reinsert your USB cable, or try another cable.
2. If you use USB adapters, try to skip them and connect directly to the USB port on your PC.
3. Open your DEVICE MANAGER, select the port, and if prompted, try to install the [CP210X driver](https://resource.heltec.cn/download/tools/CP210x_Universal_Windows_Driver.zip)
4. Try another computer or a different system
{% endstep %}

{% step %}
The serial port does not exist.

1. Open your DEVICE MANAGER, check to see if the device port can be found. If not, please refer to the previous topic “I can’t find serial port”.
2. Please check if your serial port is opened elsewhere.
3. Enter the BootLoader mode to upload, there are two ways to enter the mode:
   * connect the USB cable, hold down the User (or ORG or Boot) key, press RST once, and then release the User (or ORG or Boot) key.
   * Hold down the User (or ORG or Boot) key, then connect the USB cable.
{% endstep %}

{% step %}
What are the specifications of the sensor connection cable?

This is a 10cm sensor adapter cable with specifications ranging from SH 1.0-4P to PH 2.0-4P. It is used to connect the development board and sensors. The sh 1.0-4P port is used to connect to the interface of the development board, while the ph 2.0-4P port is used to connect to the sensor interface. If you need this product separately, you can purchase it through [this link](https://heltec.org/project/sh1-0-4p-to-ph-2-0-4p-sensor-adapter-cable/).\
[Specification of board sensor connection port](https://resource.heltec.cn/download/HT-VMT190/sh2.0_interface_4F32C39EE011CAA34840C9E4E87704C4.pdf)
