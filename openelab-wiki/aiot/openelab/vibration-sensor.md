### Introduction

The vibration module is also called the vibration switch. When we tap the module or shake the module, it will detect the vibration and the K1 pin will output a voltage difference. The module possess 4 alligator clip interfaces VCC, GND, K1, NC, which can be easily connected to the micro:bit board or the alligator clip expansion board by the alligator clip. It also possess PH2.0 cable and DuPont line port. It supports graphical programming, we can use it to make vibration alarms, analog car alarm systems, vibration switches and so on.
