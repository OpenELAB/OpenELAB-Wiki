# T-Beam Meshtastic | ESP32 LoRa GPS

### LILYGO T-Beam Meshtastic | ESP32 LoRa GPS Board for Off-Grid Networks

### Description

Meshtastic T-Beam ESP32 LoRa 433/868/915/923Mhz SX1276/SX1278 Wireless Module WiFi GPS NEO-6M With 0.96 inch OLED Display For Arduino.

### Specifications

| MCU               | ESP32                                                                                                                                                                             |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Flash             | 4MB                                                                                                                                                                               |
| PSRAM             | 8MB                                                                                                                                                                               |
| Serial Chip       | CH9102                                                                                                                                                                            |
| Wireless protocol | Wi-Fi + Bluetooth 4.2                                                                                                                                                             |
| PMU               | AXP2101                                                                                                                                                                           |
| Onboard functions | 3 Buttons (Power+IO38+Reset)                                                                                                                                                      |
| Antenna           | <ul><li>3D WiFi Antenna [Use by default]</li><li>(Support WiFi IPEX external antenna, but you need to jump resistance)</li><li>LoRa antenna</li><li>GPS ceramic antenna</li></ul> |

GPS:

* NE0-6M GPS Modules: Support GPS protocol
* Onboard RTC crystal, Support interrupt/ wakeup

LoRa:

* Long Range Low Power LoRa Transceiver
* High sensitivity: -i48dBm
* Transceive rate: 300 kbps
* Optional Hardware
* Version: SX1278\[433Mhz] / SX1276\[868/915/923Mhz]

**Display Details**

* OLED: 0.96 inch&#x20;
* Driver: SSD1306
