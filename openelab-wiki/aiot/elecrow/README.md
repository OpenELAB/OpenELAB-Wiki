# Elecrow

Elecrow develops electronics modules, display platforms, and hands-on learning hardware. Its product families include CrowPanel interfaces, CrowPi learning systems, and ThinkNode wireless devices for makers and connected-device projects.

[Browse Elecrow products on OpenELAB](https://openelab.io/collections/brands-elecrow)

### Product range

* ThinkNode mesh communication devices and gateways
* CrowPanel HMI displays and embedded user interfaces
* CrowPi learning platforms, sensors, and prototyping modules
