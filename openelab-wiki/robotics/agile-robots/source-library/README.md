The supplied files are identified below by original filename and stated revision. ## Differences that affect use

| Topic                  | Preserved distinction                                                                                                                                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Diana 7 generations    | Older supplied brochure figures (for example 26 kg/1 m/s and an older cabinet) differ from the V1.1.0 arm manual/current brochure (28 kg/2.4 m/s and matched CB-FS). Do not combine them.              |
| Thor versus Pro        | Six-axis Thor 7 and Pro differ in mass, speed, sensing and documented tool interface; the ordinary Thor 7 manual is not the Pro installation manual.                                                   |
| Controller mains       | CB-FS is 110–240 V AC; RCB Thor 3 is 200–240 V AC. Training shorthand is not a universal mains limit.                                                                                                  |
| Tool connector pins    | Diana 3 and Thor 7/12/20 M8 eight-pin assignments differ. Thor RS485A description is inconsistent; confirm polarity/cable before wiring.                                                               |
| Fasteners              | Thor 20 six M10 base and six M6 tool holes differ from the generic four-screw training example.                                                                                                        |
| Joint count and units  | Diana 7 joints / Thor 6 joints. Industrial C/C++/Python use SI; pendant Lua uses mm/ms/degrees. Embedded context Python is separate from external DianaApi.                                            |
| Diana FCI              | V1.3 covers specific FS configurations, Industrial V3.3/FCI V0.18.2, but links older libfranka examples. Exact supported client pairing is required; no gripper/suction interface support is asserted. |
| H10-W configurations   | Supplied 105 kg omnidirectional configuration differs from current public 230 kg differential-drive configuration; no blended specification or whole-body API is inferred.                             |
| Legacy safety examples | No copied jumper bypasses, blanket 30% safety claim, disabled free-drive thresholds, default safety credentials or automatic post-collision resume is used as a first-result procedure.                |
| SDK access             | Industrial/Hand/humanoid package, supported model/host and license need exact delivery verification where no public manufacturer-controlled release was confirmed.                                     |
| Update and welding     | Old V3.2 updater is not a universal V3.3 migration recipe. Welding Disabled still permits robot trajectory motion; independently inhibit welding energy for a dry run.                                 |
