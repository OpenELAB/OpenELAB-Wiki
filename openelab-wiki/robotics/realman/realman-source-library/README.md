**How to read revisions:** RM65/RM75 share one family source; ECO63/ECO65 share another. ECO62 and GEN62 are specification sheets, not substitutes for those operating manuals. S2 has a separate hardware manual and V1.3 software contract. L2 is a separate V2+ solution white paper, not an RMC-DA-LIII or S2 manual. The original legacy wiki pages and PDF downloads are retained.

**Original-page versus text view:** original images preserve complete tables, connector orientations and drawings. Extracted text is searchable but can retain native PDF reading-order/character defects. The ECO62/GEN62 sheets have visually checked transcriptions. Discrepancy notes accompany the applicable manual; supplied values have not been silently reconciled.

## How to use the citations

Wiki citations identify the source key and **original PDF page number**, counted from the first page of the uploaded file. Downloads are divided into labeled page ranges; for example, original p. 25 is page 5 of a part labeled 21–42. Text and original page ranges are retained; embedded raster illustrations were optimized for the hosted copies. The original filenames below identify the uploaded source, without treating file timestamps as manufacturer revision numbers.

The supplied documents contain translation, typography and revision differences. Current manufacturer downloads may be newer and are not automatically identical to these English files. Use a part's original page-range label when following a citation rather than assuming printed chapter pagination matches the PDF counter.

## Revision and interpretation notes

| Source                       | Boundary that affects use                                                                                                                                                          |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| RM65/RM75, RML63, RX and ECO | Power/base or installation figures differ between supplied manuals and current parameter pages. Resolve against the delivered drawing, controller and supply before powered setup. |
| ECO                          | Older retained ECO65 V1.2.0 has different wrist-brake wording from the supplied newer ECO manual.                                                                                  |
| ECO62                        | Four-page specification sheet; a complete installation/pinout manual was not supplied.                                                                                             |
| GEN62                        | Supplied sheet and current developer page differ on weight, temperature, joint limits and TCP-speed inequality; GEN62 is not GEN72.                                                |
| RMG22-65                     | Current demand exceeds the cited arm tool-port rating; use approved power integration. Some protocol configuration examples contain inconsistencies.                               |
| S2 user manual               | Translated lift/travel terminology and values conflict; use the exact S2 kinematic/control appendix.                                                                               |
| S2 interface V1.3            | “Milliradians” wording conflicts with explicit 0.001° and rad-to-millidegree formula. Command targets are millidegrees; direct state messages use their documented units.          |
| L2 V2+                       | Solution white paper, not an operating manual. S100 compute naming is inconsistent; delivered BOM governs.                                                                         |

## Review and validation scope

Reviewed 22 November 2026. All ten supplied PDFs were inventoried and their model-specific specification, setup and development sections reviewed; raster-only specification sheets and representative connector/unit tables were visually inspected. Store matches and official SDK/document sources were checked. Source review does not prove software or hardware operation. SDK installation, compilation, live ROS communication, calibration, load tests and robot motion were **not run**.
