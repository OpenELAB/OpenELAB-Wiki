# FEETECH

FEETECH develops servos and servo-control hardware for robotics and model applications. Its serial-bus servo families are useful for multi-joint mechanisms because compatible servos can share a communication bus and expose configuration and feedback data.

[Browse FEETECH products on OpenELAB](https://openelab.io/collections/brands-feetech)

### Product range

* STS, SMS, SCS, and other serial-bus servo families
* Compact and higher-torque robotic servos
* Host software, SDKs, communication protocols, and memory-map references

### Popular applications

* Build small robot arms and leader-follower teleoperation systems.
* Develop multi-servo hands, legged robots, and articulated models.
* Read feedback and configure compatible servos from embedded controllers.

The linked memory table is a family reference. Verify voltage, gear ratio, firmware, and communication protocol for the exact servo variant.
