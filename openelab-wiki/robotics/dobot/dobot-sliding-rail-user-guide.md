### Demo Description

This topic describes how to use sliding rail for writing. Prerequisites

* The sliding rail has been installed and connected to the Dobot Magician.
* Dobot Magician has been powered on. Dobot Magician has been connected to

DobotStudio successfully.

* The writing kit has been installed.
* The PLT files have been prepared.
