## 2. Installation Steps

1. Place the base plate flat on cardboard or other soft material (to avoid scratching the base plate). Securely attach the four casters to the four corners of the base plate using M6×20 screws.

**NOTE** The side with the curve is the front-facing side.

![Official manual image, source page 6](https://1292444914-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FtgOfPnscWebs1eh82EKq%2Fuploads%2F2vR9L8PrpBewcXwC7ypQ%2Fcra-education-p006-img02.jpg?alt=media)

2. After assembly, flip the entire base plate upside down and secure the column to the base plate using M12x40 screws.
3. Use M8x20 screws to secure the two small columns to the base plate. Note that the screws for the small columns should not be fully tightened at this stage; they should only be tightened after completing the base plate assembly.

![Official manual image, source page 7](https://1292444914-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FtgOfPnscWebs1eh82EKq%2Fuploads%2FXih25KXRkS08PXbHwT1Q%2Fcra-education-p007-img01.jpg?alt=media)

![Official manual image, source page 7](https://1292444914-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FtgOfPnscWebs1eh82EKq%2Fuploads%2FkiQ867pFLiAeFp9JHmpk%2Fcra-education-p007-img02.jpg?alt=media)

4. Use M5x12 screws to attach the panel to the column.
