# Yahboom

Yahboom develops robotics learning platforms built around controllers such as Raspberry Pi and NVIDIA Jetson. Its range combines mobile robots, robot arms, sensors, and software examples for learning AI vision and ROS.

[Browse Yahboom products on OpenELAB](https://openelab.io/collections/yahboom)

### Product range

* ROSMASTER and MicroROS mobile robot platforms
* DOFBOT and JetCobot robotic arms
* Vision modules, robot chassis, and embedded robotics learning kits

### Popular applications

* Learn ROS 2 mapping, navigation, and obstacle avoidance.
* Develop AI vision and camera-guided robotic grasping.
* Compare mobile-robot drive types and embedded control methods.
