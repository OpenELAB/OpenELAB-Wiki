# WowRobo

WowRobo supplies kits and components for open-source robotics projects. Its OpenELAB collection includes leader-follower arms, mobile robot kits, dexterous hands, and tactile-sensing hardware used in the LeRobot and broader robot-learning community.

### Popular applications

* Collect teleoperation demonstrations for imitation learning.
* Build mobile-manipulation and dual-arm research prototypes.
* Explore dexterous manipulation and tactile feedback.

These kits implement community projects with their own upstream documentation. Confirm the kit revision and project bill of materials before following assembly or software instructions.
