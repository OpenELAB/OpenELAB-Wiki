## How to use the references

The manuals and brochures below are the files supplied for this review. Long PDFs are divided into original-page-range parts. A citation to original p. 60 in a part labeled 051–070 means page 10 of that download. Training decks have slide-numbered **PDF reading copies**; the supplied PPTX remains the authoritative native file. Text extraction and visual slide review informed the tutorials. Reading copies preserve the slide sequence and may render fonts/layout differently from PowerPoint.

The manufacturer supplies separate hardware and System Image-specific operating manuals. Document numbers, hardware versions and System Images are not interchangeable. Current official editions below are listed separately from the supplied files.

## Revision differences that affect use

| Topic                                  | What this series preserves                                                                                                                                                            |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Arm hardware vs operating instructions | Supplied Arm v2.1 R02210/1.2 is distinct from newer R02210/1.3 and System Image-specific R02216 manuals.                                                                              |
| Old training page numbers              | Desk slides use older combined-product-manual references; the Safety slide repeats a log-download reference. Use the matching manual's semantic section.                              |
| Network paths                          | X5 UI access and C2 FCI access are different networks. Mobile internal addresses are delivery-specific.                                                                               |
| SDK example                            | The 5.10 operating PDF still shows a legacy libfranka 0.10.0 command; use the current System Image/library compatibility matrix instead.                                              |
| World interface                        | 2025 “Account” screenshots differ from the current World 2.0 organization workflow.                                                                                                   |
| Prototype ratings                      | Brochure dimensions, base payload, speed and camera counts differ from later v0.2 documents and kit configurations. No combined maximum is asserted.                                  |
| Duo DOF                                | Two seven-axis arm chains have 14 arm joints; brochure total counts are not a universal control-vector length.                                                                        |
| Hand                                   | Separate gripper interface; arm 1 kHz control does not guarantee real-time Hand finger control.                                                                                       |
| GELLO                                  | Franka-contributed implementation is hosted in the original author's repositories; starting a publisher can configure leader torque, and follower launch can synchronize immediately. |

## Review and validation

Reviewed 22 November 2026. The seven source PDFs and all 43 training slides were inspected, with current official operating/SDK sources checked for model and version scope. Hosted source links, internal navigation and saved content were validated separately from physical operation. No robot connection, SDK compilation, simulation, gripper motion, mobile motion or hardware safety test was run.

Expanded source review: the seven repeated Franka PDFs in the 34-file Agile Robots/Franka batch match these files by SHA-256 and are reused here. The [Agile Robots source library and revision notes](../agile-robots/source-library.md) covers the additional Diana/Thor/controller/V3.3 manuals, six distinct Agile Robots training decks and authorized H10-W/H20 specification summaries.
